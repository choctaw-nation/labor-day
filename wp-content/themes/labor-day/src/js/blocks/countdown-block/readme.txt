A beautiful and customizable countdown timer block that counts down to any future date and time.

== Description ==

Create engaging countdown timers for your WordPress site with this powerful block. Perfect for event announcements, product launches, sales deadlines, or any time-sensitive content.

**Features:**

* **Easy Date & Time Selection** - Use the intuitive date and time picker to set your target countdown date
* **Fully Customizable Display** - Toggle individual time units (days, hours, minutes, seconds) on or off
* **Custom Labels** - Personalize the labels for each time unit to match your site's language and style
* **Typography Controls** - Customize font size, colors, and styling for both numbers and labels
* **Flexible Alignment** - Align your countdown timer left, center, or right
* **Completion Message** - Display a custom message when the countdown reaches zero
* **Live Preview** - See exactly how your countdown will look while editing in the block editor
* **Real-Time Updates** - Countdown updates every second on the frontend with smooth JavaScript animations
* **Timezone Aware** - Respects your WordPress site's timezone settings
* **Graceful Handling** - Automatically shows completion message for expired countdowns

**Perfect For:**

* Event countdowns
* Product launch timers
* Limited-time offer deadlines
* Webinar registration deadlines
* Holiday countdowns
* Anniversary celebrations
* Booking deadlines
* And much more!

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/countdown-timer` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Add the "Countdown Timer" block to any post or page using the block editor
4. Configure your countdown date, time, and styling options in the block settings

== Frequently Asked Questions ==

= How do I set the countdown date? =

In the block toolbar or sidebar settings, you'll find a date picker control. Click it to select your target date and time.

= Can I customize the appearance? =

Yes! The block includes extensive customization options including colors, typography, alignment, and the ability to show or hide individual time units.

= What happens when the countdown reaches zero? =

The countdown will display your custom completion message. You can set this message in the block settings.

= Does it work with my timezone? =

Yes, the countdown timer respects your WordPress site's timezone settings configured in Settings > General.

= Can I show only certain time units? =

Absolutely! You can toggle days, hours, minutes, and seconds on or off individually in the block settings.

= Does the countdown update in real-time? =

Yes, the countdown updates every second on the frontend using efficient JavaScript.

== Usage ==

After installing and activating the plugin:

1. Create or edit a post or page
2. Add the "Countdown Timer" block from the block inserter
3. Set your target date and time using the date picker in the toolbar
4. Customize the appearance using the settings in the sidebar:
   - Toggle time units on or off
   - Customize labels for each unit
   - Adjust colors and typography
   - Set alignment
   - Configure your completion message
5. Publish or update your page to see the countdown in action

The countdown will automatically update every second, and when it reaches zero, your completion message will be displayed.
